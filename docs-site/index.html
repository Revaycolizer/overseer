Overseer SDK

Programmatic access to the Overseer AI orchestration platform. Available in Rust, Python, and TypeScript.

🦀 Rust

cargo add overseer-client

Type-safe HTTP client with 100+ methods covering all API endpoints.

🐍 Python

pip install overseer-pysdk

Async SDK with Pydantic models, rich CLI, and 16 namespaced API modules.

📦 TypeScript

npm install overseer-client

Zero-dependency client with native fetch, full type declarations, works in browser and Node.js.

use overseer_client::OverseerClient;

let client = OverseerClient::new("http://localhost:8080")?

Quickstart

Get started with the Overseer SDK in under 5 minutes.

1. Install the SDK

cargo add overseer-client
pip install overseer-pysdk
npm install overseer-client

2. Connect and verify

use overseer_client::OverseerClient;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let client = OverseerClient::new("http://localhost:8080")?
        .with_token("my-token");

    // Check health
    let health = client.health().await?;
    println!("Server: {} (v{})", health.status, health.version);

    // List conversations
    for conv in client.list_conversations(10).await? {
        println!("#{}: {}", conv.id, conv.title);
    }
    Ok(())
}
import asyncio
from overseer import OverseerClient

async def main():
    async with OverseerClient("http://localhost:8080", token="...") as c:
        health = await c.system.health()
        print(f"Server: {health.status} (v{health.version})")

        for conv in await c.conversations.list():
            print(f"#{conv.id}: {conv.title}")

asyncio.run(main())
import { OverseerClient } from 'overseer-client';

const client = new OverseerClient({ baseUrl: 'http://localhost:8080' });
const health = await client.system.health();
console.log(`Server: ${health.status} (v${health.version})`);

const conversations = await client.conversations.list();
for (const conv of conversations) {
    console.log(`#${conv.id}: ${conv.title}`);
}

Migration Guide

Transition from raw HTTP to the SDK clients.

Rust: reqwest → overseer-client

Before:

let resp = reqwest::Client::new()
    .get("http://localhost:8080/api/conversations")
    .header("Authorization", "Bearer token")
    .send().await?;
let data: Vec<Value> = resp.json().await?;

After:

let client = OverseerClient::new("http://localhost:8080")?
    .with_token("token");
let conversations = client.list_conversations(10).await?;

Python: httpx → overseer-pysdk

Before:

async with httpx.AsyncClient() as http:
    r = await http.get("http://localhost:8080/api/agents",
        headers={"Authorization": "Bearer token"})
    agents = r.json()

After:

async with OverseerClient("http://localhost:8080", token="...") as c:
    agents = await c.agents.list()
